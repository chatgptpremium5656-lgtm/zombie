# Zombie (рабочее название)

Кооп-выживание на Unity: строительство в духе Rust + орда зомби каждую ночь. Бесконечное выживание, вид от первого лица, мультяшная графика.
Платформы: сначала macOS, позже iOS и Android.

Правила для разработки и арта — в [CLAUDE.md](CLAUDE.md).

## Статус

Перезапуск с нуля (27.10.2026). Сейчас в проекте тестовая сцена для оценки стиля (`Assets/Scenes/Main.unity`) и проверенная тестами логика. Геймплей ещё не начат: сначала владелец утверждает внешний вид.

| Папка | Что внутри |
|---|---|
| `Assets/Scenes/Main.unity` | тестовая сцена: поляна, костёр, разбитая машина, зомби, руки с каменным топором, HUD |
| `Assets/Art/Models` | модели из Blender (FBX, гладкие формы, цвет в вершинах) |
| `Assets/Art/Shaders` | `Zombie/Toon` (мягкий ramp-свет, цветные тени, rim, ветер, трава), небо-градиент, частицы |
| `Assets/Prefabs` | готовые префабы: деревья, камни, кусты, костёр, машина, забор, зомби, облака |
| `Assets/Scripts` | рендер (атмосфера, трава), игрок (управление, анимация рук), мир (реакции на удар, костёр), HUD |
| `Assets/Scripts/Logic` | инвентарь, предметы, сетка строительства, план волн (без UnityEngine) |
| `Assets/Editor` | сборщик сцены и контента |
| `Assets/Tests/EditMode` | тесты логики (Window → General → Test Runner) |
| `Tools/Blender/build_assets.py` | генератор всех моделей |

### Как пересобрать

1. Модели: `Blender -b --factory-startup -P Tools/Blender/build_assets.py -- Assets/Art/Models`
2. Сцена и контент: меню **Zombie → Build Test Scene** (или `-executeMethod Zombie.EditorTools.SceneBuilder.BuildAll`). Сборщик заново создаёт материалы, землю, префабы, иконки и `Main.unity`.

### Управление

WASD — ходьба, Shift — бег, Space — прыжок, мышь — обзор (клик захватывает курсор, Esc отпускает), ЛКМ — удар топором, 1–6 или колесо — слот.
