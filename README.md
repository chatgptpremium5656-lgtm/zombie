# Last Stand (рабочее название)

Кооп-выживание на Unity: строительство в духе Rust + орда зомби каждую ночь. Бесконечное выживание, вид от первого лица, мультяшный low-poly.
Платформы: сначала macOS, позже iOS и Android.

Правила для разработки и арта — в [CLAUDE.md](CLAUDE.md).

## Как запустить (Mac)

1. Установи **Unity Hub** и **Unity 6 LTS** (любая версия 6000.x) с модулем *Mac Build Support*.
2. Склонируй репозиторий и в Unity Hub нажми **Add → Add project from disk**, выбери папку `zombie`.
   Если Hub спросит версию — выбери установленную Unity 6.
3. При первом открытии проект сам настроится (меню **Zombie → Run Project Setup** запускает это ещё раз):
   поставит пакеты URP и Input System, создаст URP-ассет, материал палитры, `GameConfig` и сцену `Assets/Scenes/Main.unity`.
   Если Input System спросит про перезапуск и включение новых бэкендов — нажми **Yes**.
4. Открой `Assets/Scenes/Main.unity` и нажми **Play**. Вся игра собирается из кода при старте, ничего настраивать в сцене не нужно.
5. Сборка для Mac: **File → Build Profiles → macOS → Build**.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / Shift / Space | ходить / бег / прыжок |
| ЛКМ | бить, добывать, ставить постройку |
| ПКМ | план постройки: сменить деталь; молоток: улучшить |
| R | повернуть лестницу |
| 1–9, колесо | выбрать предмет |
| Tab или C | меню крафта |
| E | открыть/закрыть дверь |
| F | фонарик |
| Esc | пауза |

## Что есть в прототипе

- Маленькая тестовая карта 160 × 160 м: деревья, камни, металлическая руда, ресурсы отрастают.
- Цикл день/ночь ≈ 7 минут (настраивается в `GameConfig`).
- Крафт: каменный топор, кирка, копьё, мачете, план постройки, молоток, спальник, колья.
- Строительство по сетке 3 × 3 м: фундамент, стена, дверной проём, дверь, перекрытие (этажи), лестница.
  Улучшение молотком: солома → дерево → камень → металл. Без опоры постройки рушатся.
- Орда каждую ночь, растёт с каждой ночью: шаркуны, бегуны, громилы. Зомби ломают стены и двери на пути.
  Остатки орды сгорают на рассвете. Рекорд ночей сохраняется.
- Смерть: возрождение в спальнике, всё, что было с собой, теряется.

## Структура

| Папка | Что внутри |
|---|---|
| `Assets/Scripts/Logic` | чистая логика без Unity: инвентарь, предметы, сетка строительства, план волн (покрыта тестами) |
| `Assets/Scripts/Core` | старт игры, ввод, палитра, процедурные low-poly модели, конфиг |
| `Assets/Scripts/World` | карта, ресурсы, день/ночь |
| `Assets/Scripts/Player` | движение, инструменты, смерть/респаун |
| `Assets/Scripts/Building` | строительство, двери, колья |
| `Assets/Scripts/Zombies` | зомби, орда, пул объектов |
| `Assets/Scripts/UI` | HUD и меню прототипа |
| `Assets/Tests/EditMode` | тесты (Window → General → Test Runner) |
