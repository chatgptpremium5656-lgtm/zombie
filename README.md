# Zombie (рабочее название)

Кооп-выживание на Unity: строительство в духе Rust + орда зомби каждую ночь. Бесконечное выживание, вид от первого лица, мультяшная графика.
Платформы: сначала macOS, позже iOS и Android.

Правила для разработки и арта — в [CLAUDE.md](CLAUDE.md).
